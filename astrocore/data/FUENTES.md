# Fuentes de datos

Estos archivos se generan con `python scripts/build_catalogs.py`.

| Archivo | Fuente | Licencia |
|---|---|---|
| `stars.csv` | HYG Database v4.1 — David Nash / astronexus (https://github.com/astronexus/HYG-Database). Filtrado a magnitud ≤ 6.5. | CC BY-SA 4.0 |
| `dso.csv` | OpenNGC — Mattia Verga (https://github.com/mattiaverga/OpenNGC). Messier, objetos con nombre común o magnitud ≤ 10. | CC BY-SA 4.0 |
| `constellation_bounds.dat` | Roman, N. G. (1987), *Identification of a Constellation from a Position*, PASP 99, 695. VizieR VI/42. Límites en equinoccio B1875.0. | Dominio público (datos CDS) |

Los derivados de HYG y OpenNGC se redistribuyen bajo la misma licencia CC BY-SA 4.0.
